# 배포 자동화 (auto_deploy)

**설명:** 서버 배포 과정을 자동화합니다.
**트리거:** 사용자가 "서버에 배포해 줘"라고 요청할 때

**동작 순서:**
1. 테스트 코드를 먼저 실행합니다. (예: `npm test`)
2. 테스트가 성공하면 `npm run build` 명령어를 실행하여 빌드합니다.
3. 빌드가 성공적으로 완료되면 생성된 빌드 폴더(예: `dist`)를 `.zip` 파일로 압축합니다. (PowerShell의 `Compress-Archive` 명령어 사용 등)
4. 압축이 끝나면 작업이 완료되었음을 사용자에게 알려줍니다.
